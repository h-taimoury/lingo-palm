FFMPEG INSTALLATION AND INSPECTION
Installation command used:

Reopen Terminal after installation; verify ffmpeg -version and ffprobe -version.
Inspect codecs/audio language before recommending conversions:
ffprobe -v error -show_entries stream=index,codec_type,codec_name:stream_tags=language -of json "MOVIE.mkv"
Audio indexes in -map 0:a:N are zero-based indexes among audio streams, not
absolute stream indexes. First audio = 0:a:0; second audio = 0:a:1.

PREFERRED MANUAL SPLITTING COMMAND
Run from the movie folder in PowerShell. Replace filename, folder, and cut times.
The example below selects the SECOND audio track, as needed for Finding Nemo:

Set-Location -LiteralPath "C:\Users\Fardin\Desktop\Finding Nemo"
New-Item -ItemType Directory -Path "FindingNemo-parts" -Force
ffmpeg -n -i "Finding.Nemo.2003.1080p.mkv" -map 0:v:0 -map 0:a:1 -sn -dn -map_metadata -1 -map_chapters -1 -c copy -f segment -segment_times 00:30:00,01:00:00 -segment_start_number 1 -reset_timestamps 1 "FindingNemo-parts/section%d.mp4"

The times above are EXAMPLES, not the actual Finding Nemo boundaries used in
the existing files. The third section continues to EOF, with no fixed end time.
Segment cuts use available keyframes and can fall after requested times.
For a movie whose first audio track is the desired English track, use 0:a:0.
Do not use -map "0:a?" when the user wants ONLY English: that selects all audio.

EXISTING MKV SECTIONS TO MP4
Convert the existing sections directly rather than re-splitting the original:
ffmpeg -n -i "section1.mkv" -map 0:v:0 -map 0:a:0 -sn -dn -map_metadata -1 -map_chapters -1 -c copy -movflags +faststart "section1.mp4"
Select the actual desired audio index; do not blindly use 0:a:0.
Repeat for section2 and section3. This command excludes subtitle tracks, but
cannot remove text burned into the picture. External VTT files are independent.

FORMATS AND PLAYBACK
MKV and MP4 are containers. -c copy remuxes compatible streams without
re-encoding: usually fast and approximately the same size, with unchanged quality.
An MP4 extension alone does not guarantee browser compatibility. H.264 video
(8-bit yuv420p) and AAC audio are the preferred broad-compatibility combination.
If existing codecs are incompatible, inspect first: audio-only conversion may
suffice; video re-encoding is slower and can change size and quality.
Do not re-encode automatically just because a browser reports unsupported media.
The admin player uses HTML video and shared HLS support. For failures, inspect
the saved Video URL, filename/extension, HTTP status/content type, and codecs.
A previous 12 Angry Men failure was a saved .mkv URL pointing to a real .mp4 file
(404); it was NOT a codec problem. The MP4 was already H.264/AAC.

  Remove orphaned dashes or empty lines left by removing labels.

- Deliver clickable links to individual VTT files plus a ZIP containing them.

COURSE DATA AND FUTURE CHANGES
Sections store video_url separately from subtitle files and word mappings.
Mappings rely on subtitle cue IDs, exact words, occurrence identifiers, and
stored cue timestamps, not video filenames/extensions. Keeping the same section
timeline allows replacing a video URL/container without recreating mappings.
Recheck synchronization after remuxing, transcoding, or provider processing.
Changing cuts, trimming, speed, subtitle cue numbering, or mapped text can break
timing or mappings. Finalize videos and subtitle cleanup BEFORE creating mappings.
Keep originals and finalized section files so future conversions reuse exact cuts.
